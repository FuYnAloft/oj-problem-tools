# 整数序列求和

## 描述

给定一个整数序列，求所有整数之和。

## 输入格式

第一行包含一个整数 $N$（$1 \le N \le 1000$）。

第二行包含 $N$ 个整数 $a_1,a_2,\ldots,a_N$（$-10^9 \le a_i \le 10^9$）。

## 输出格式

输出一个整数，表示序列中所有整数之和。

## 样例

**样例输入**

```text
3
1 2 3
```

**样例输出**

```text
6
```
